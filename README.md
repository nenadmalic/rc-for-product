# RevenueCat for Product: landing page concept

An independent concept for a RevenueCat landing page aimed at product managers.

**Live page:** https://rc-for-product-beta.vercel.app/

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` for a production build.

## Built with

React, TypeScript and Vite. Deployed on Vercel.
